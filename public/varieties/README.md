# Mango variety images

Drop the photo for each variety here, using the filename referenced in
`src/OrderPage.tsx` (the `image` field of each entry in `VARIETIES`).

Current expected files:

- `banganapalli.jpg`
- `dasheri.jpg`
- `himayat.jpg`

Recommended: roughly square images, ~600x600px, JPEG. If you change a
filename, update the matching `image` value in `OrderPage.tsx`.
